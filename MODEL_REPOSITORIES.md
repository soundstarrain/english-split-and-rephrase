# Model repositories

These are the two Hugging Face model repositories used by the companion code.

| Repository | Task | Base model |
|---|---|---|
| `soundstarrain/english-split-and-rephrase-gate` | stop/continue classification | `answerdotai/ModernBERT-base` |
| `soundstarrain/english-split-and-rephrase-rewriter` | one sentence to two sentences | `google-t5/t5-base` |

The code repository accepts either local paths or these Hugging Face model IDs.
